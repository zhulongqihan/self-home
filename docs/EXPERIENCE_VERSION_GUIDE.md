## 三、你必须亲手完成（仅 4 步）

> 微信不允许第三方代你点「上传」和公众平台后台，以下只能你本人操作。  
> 预估总时间：**15～25 分钟**（第一次）。

### 步骤 1：确认合法域名（约 3 分钟，只做一次）

1. 浏览器打开：**https://mp.weixin.qq.com**
2. 扫码登录 → 进入你的小程序后台（AppID 以 `wxb6802a3a7b606136` 结尾的那个）
3. 左侧 **开发** → **开发管理** → 切到 **开发设置** 标签
4. 找到 **服务器域名** → **request 合法域名** → **修改**
5. 在列表中确认已有（没有就添加）：
   ```text
   https://api.cyruszhang.online
   ```
6. 规则：
   - 必须 `https`
   - **不要** 带路径、不要末尾 `/`
   - 每月修改次数有限，保存前核对
7. 点 **保存并提交** → 等待 1～5 分钟生效

**如何确认已生效**：真机体验版里能打开厨房商品列表；若提示「不在以下 request 合法域名列表中」，就是这一步没配好。

## 十、排错大全

| 现象 | 原因 | 处理 |
|------|------|------|
| 她扫码「无权限」 | 未加体验成员或未接受邀请 | 成员管理 → 体验成员 |
| request 合法域名错误 | 未配 `api.cyruszhang.online` | 步骤 1 |
| 店铺暂未营业 | 顾客 openid 不在白名单且未用暗号 | 用暗号登录或附录 A |
| 暗号不对 | 已改密仍用旧的 | 用新暗号或店长端再改 |
| 界面一直是旧的 | 缓存旧包 | 删小程序 → 重扫体验码 |
| 401 登录过期 | token 失效 | 重新输入暗号 |
| 上传按钮灰色 | 非开发者身份 | 成员管理加开发者 |
| 订阅消息收不到 | 她点了拒绝 | 某次下单时点允许 |

## 附录 A：补她的 openid 到白名单（可选）

仅当她要 **微信自动登录**、不想记暗号时需要。

1. 她先扫 **预览码** 或体验码进 **店铺暂未营业** 页（或 forbidden 页）
2. 页面上有 openid，让她 **点击复制** 发给你
3. 你本机终端执行（把 `她的openid` 换成真实字符串）：

```bash
ssh root@118.31.221.81 "mongosh couple_app --quiet --eval \"
db.config.updateOne(
  { _id: 'global' },
  { \\\$set: { 'whitelist.customer_openid': '她的openid' } }
)
\""
```

4. 无需重启 pm2；她重新打开小程序即可自动识别为顾客
